# 心动模式升级方案 · 长期记忆 + 主动陪伴

## Context

「心动模式」是爱弥斯的 galgame 式角色交互页（`src/aemeath_agent/galgame/`，前端 `galgame/web/`）。
现状：每轮对话只把 `save.history[-26:]` 拼进模型上下文（`engine.py:66` `HISTORY_LIMIT=26`），
**关掉页面再进来她就忘了之前聊过什么**；并且永远是玩家先开口，她从不主动。

要对标市面上的 AI 陪伴产品（如星野）的「陪伴感」，核心是两件事：**连续感**（她记得你、记得你们之间发生的事）
与**主动性**（她会主动找你说话）。本次只做这两个方向，做深做透。

用户已确认：
- 主动陪伴：**打开时的久别问候 + 页内闲置主动搭话 + 允许她主动开启普通事件**
- 长期记忆：**只读共享主控制台画像 + 心动模式独立关系记忆**（不回写，避免角色扮演内容污染主控制台的工具型画像）

不作为本次目标（写入「第二阶段预留」）：CG/演出表现升级、装扮/礼物等玩法。

## 设计总览

```
                 ┌─────────────────────────────┐
  主控制台陪伴模式 │  MemoryManager (共享画像)     │  ← 只读，注入
                 │  ~/.aemeath_agent/memory/    │
                 └──────────────┬──────────────┘
                                │ profile_block()
  心动模式         ┌────────────▼──────────────┐
  独立记忆目录     │  GalgameMemory (新模块)      │
                 │  ~/.aemeath_agent/galgame/   │
                 │      memory/                 │  ← 读写独立，互不污染
                 └──────────────┬──────────────┘
                                │
                  ┌─────────────▼──────────────┐
                  │  GalgameEngine              │
                  │  · _build_messages 注入记忆  │
                  │  · chat 尾部写入 + 剧情压缩   │
                  │  · proactive() 主动发言      │
                  └─────────────────────────────┘
```

两条硬性原则（决定现有测试能否保持全绿）：

1. **记忆只拼进 `messages[0]["content"]`（system 字符串），绝不新增 message**。
   现有 `tests/test_galgame.py::test_assistant_history_is_json_enveloped` 与
   `test_transcript_stays_alternating` 锁定 `messages` 的 roles 必须是 `system` + user/assistant 严格交替。
2. **`GalgameEngine.__init__(memory=None)` 默认关闭所有记忆逻辑**（`if self.memory is None: return` 短路）。
   现有 406 项测试构造引擎时不传 memory → 行为零变化，不会多消费 FakeLLM 脚本队列。

## 一、数据模型改动

### `galgame/state.py`

`save_dir()` 保持不变（`~/.aemeath_agent/galgame/`），新增派生目录：

```python
def memory_dir() -> Path:
    """心动模式专属记忆目录（与主控制台会话画像隔离）。"""
    return save_dir() / "memory"
```

`GalgameSave` 新增 6 个字段（全部带默认值 → `load_save()` 的
`k in GalgameSave.__dataclass_fields__` 过滤保证**旧存档天然兼容**）：

```python
# ---- 长期记忆 ----
memories: List[Dict[str, Any]] = field(default_factory=list)
#   剧情回忆，元素形如 {"turn": int, "chapter": int, "text": str, "at": "YYYY-MM-DD HH:MM:SS"}
memory_cursor: int = 0            # 已压缩到 total_turns 的哪一轮（避免重复压缩）
# ---- 主动陪伴 ----
last_interaction_at: str = ""     # 最后一次「玩家主动互动」时间（ISO，仅玩家发言时更新）
last_proactive_at: str = ""       # 最后一次「她主动发言」时间
proactive_count: int = 0          # 当日已主动次数
proactive_count_date: str = ""    # "YYYY-MM-DD"，跨日归零
```

`to_public()` 走 `asdict`，新字段自动暴露给前端（HUD 显示「回忆 N 条」）。

### `galgame/engine.py` 顶部常量

```python
MEMORY_INTERVAL = 12           # 兜底压缩间隔（轮）
MEMORY_KEEP = 8                # 注入上限（条）
MEMORY_CHAR_LIMIT = 120        # 单条回忆字数上限
MEMORY_MAX_ITEMS = 24          # 存档内回忆总条数上限
RESUME_GAP_HOURS = 6.0         # 「久别问候」最小离线时长
IDLE_MIN_SECONDS = 180         # 「闲置搭话」后端校验下限（前端 5 分钟触发）
PROACTIVE_COOLDOWN_MIN = 20    # 两次主动发言最小间隔
PROACTIVE_DAILY_CAP = 4        # 每日主动发言次数上限
```

## 二、后端改动点

### 1. 新模块 `galgame/memory.py` — `GalgameMemory`

封装「独立目录的 MemoryManager」+「只读共享画像」，复用现有 `src/aemeath_agent/memory/__init__.py`
的 `MemoryManager`（构造可注入目录，测试友好）：

```python
class GalgameMemory:
    def __init__(self, directory=None):
        self.mm = MemoryManager(directory or memory_dir())   # 独立读写
    def profile_block(self) -> str:
        """主控制台画像（只读）+ 心动模式自己的画像。任一段失败都跳过。"""
    def record(self, user_text, reply) -> int: ...           # 转发 self.mm.record
    def threshold_reached(self, threshold) -> bool: ...      # 转发
    def summarize(self, client, model) -> None: ...          # 转发，异常吞掉
```

> 复用点：`MemoryManager.record / threshold_reached / summarize / profile_block`
> （`src/aemeath_agent/memory/__init__.py:106-303`），以及主控制台
> `AgentChatService._maybe_remember` 的旁路容错写法（`llm/agent_router.py:439-455`）作为模板。

### 2. `galgame/engine.py`

- `__init__(self, settings=None, rng=None, memory=None)` —— 新增 `memory` 形参并存为 `self.memory`。
- `chat()` 尾部接线（在 `persist(save)` 之前，**全部 try/except 旁路，任何失败不影响对话**）：

  ```python
  save.last_interaction_at = _now_iso()
  if transition:                                            # 章节切换 / 结局（确定性时机）
      await asyncio.to_thread(self._compress_memory, save, world, "transition")
  elif save.total_turns - save.memory_cursor >= MEMORY_INTERVAL:
      await asyncio.to_thread(self._compress_memory, save, world, "interval")
  await asyncio.to_thread(self._record_memory, message, reply)
  ```

- `_compress_memory(save, world, reason)`：把 `save.history[memory_cursor:]` 中 user/aemeath 内容
  交给 LLM 压成 1 段 ≤120 字回忆，追加进 `save.memories`（截断到 24 条），推进 `memory_cursor`。
  LLM 失败/离线时用**确定性模板兜底**（`第N章，我们一起聊了K轮，{世界提示}`），保证「一定有记忆」。
- `_record_memory(user_text, reply)`：`self.memory.record(...)`，达到
  `settings.get_memory_threshold()` 时调 `self.memory.summarize(client, model)`。
- `_build_messages(...)` 新增关键字参数 `proactive: Optional[str] = None`，在 `【当前状态】` 之后拼入：

  ```
  【你长期记忆中关于用户的信息】(GalgameMemory.profile_block()，空则整段省略)
  【你们之间的回忆】（你确实经历过这些，可自然回忆，但不要逐条复述）
  - {最近 MEMORY_KEEP 条回忆}
  【本轮由你主动发起】{proactive 提示}   ← 仅主动发言时出现
  ```

  **不新增 message**，`roles` 结构完全不变。
- 新增 `async def proactive(self, reason: str = "resume") -> Dict[str, Any]`：
  - 守卫：未开始 / 已结局 → `{...public_state, "skipped": True}`
  - `_proactive_allowed(save, reason)`：冷却（`PROACTIVE_COOLDOWN_MIN`）、当日上限
    （`PROACTIVE_DAILY_CAP`，跨日归零）、`resume` 需离线 ≥ `RESUME_GAP_HOURS`、
    `idle` 需距上次互动 ≥ `IDLE_MIN_SECONDS`；不满足返回 `skipped` + 原因
  - `resume` 时 `self._get_world(force=True)` 重拉真实天气；按 reason + 时段/天气生成
    `proactive` 提示（早安 / 深夜怎么还不睡 / 久别 / 沉默找话题）
  - 复用 `_ask()` / `_resolve_event()`；**主动轮不改好感、不推进轮数/章节**（防刷）；
    `event_view.tier == TIER_HEARTLINK` 时丢弃事件（心链必须由玩家郑重回应、走 `forced` 通道）
  - 离线/空回复 → 确定性问候兜底并标记 `offline=True`
  - 更新 `last_proactive_at` / `proactive_count` / `proactive_count_date`，`persist(save)`，
    返回与 `chat()` 同构的 payload（`proactive: True, affinity_delta: 0`）

### 3. `galgame/__init__.py`

导出 `GalgameMemory`。（`memory` 包不 import galgame，无循环依赖。）

### 4. `server.py`

- `get_galgame_engine()` 改为 `GalgameEngine(get_settings(), memory=GalgameMemory())`。
- 新增请求模型与路由，**必须放在 `app.mount("/galgame", ...)`（L684）之前**：

  ```python
  class GalgameProactiveRequest(BaseModel):
      reason: str = "resume"      # resume | idle

  @app.post("/galgame/api/proactive")
  async def galgame_proactive(req: GalgameProactiveRequest) -> Dict[str, Any]:
      return await get_galgame_engine().proactive(req.reason)
  ```
