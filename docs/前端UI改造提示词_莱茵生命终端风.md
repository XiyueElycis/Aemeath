# 爱弥斯桌面端 UI 改造提示词（莱茵生命科技终端 × 爱弥斯）

> 用途：把爱弥斯桌面端（`desktop/AemeathAgent.Desktop`，WPF）现有的「白底 + 蓝主色 + 粉点缀」新拟物界面，升级为「莱茵生命科技终端 × 爱弥斯」的克制 HUD 风格，并与配套的启动动画（见《启动动画提示词_爱弥斯版.md》）无缝衔接——**两套界面同源、不冲突**。
> 适用对象：可直接交给开发者或 AI 编程代理按此改造 `App.xaml` / `MainWindow.xaml` / `GalgameWindow.xaml` / `src/aemeath_agent/galgame/web/styles.css`。

---

## 0. 总原则（先读）

1. **不推翻现有信息架构**：侧边栏 + 顶栏 + 聊天区 + 设置面板的布局保持不变，只升级视觉语言。
2. **三色语义**：冰蓝 `#2E6BE6` = 主操作与系统数据；青绿 `#55CBB0` / `#72E0C1` = 生物/状态数据；粉 `#F0558E` = 爱弥斯角色身份（品牌、心动模式、爱弥斯气泡、欢迎时刻）。**粉只做点缀，不做主色。**
3. **连续性优先**：启动动画最后一帧（过曝洗白后的浅色画面）的元素与主界面首帧一一对应：左上角品牌块、右上角 HUD、右下角页脚、等宽数据字体、底色。用户从启动动画进主界面时，感觉是"同一个系统亮起来"，而不是换了个界面。
4. **动画克制**：所有动画为状态服务（连接、思考、消息、切换），默认开启但提供「减少动画」开关；60fps，仅用 Opacity / Transform 等 GPU 友好属性。

## 2. 布局与元素改造（改 `MainWindow.xaml`）

### 2.1 侧边栏（品牌 + 导航 + 智能体 + 状态）
- **品牌块**（左上）：改为终端品牌块——40px 圆角 Logo（`brand.png`）不变，右侧两行改为：
  - 主行「爱弥斯」（不变，Bold 15px）
  - 副行改为等宽小字 `AEMEATH AGENT · 星海轻歌`（11px，`DataFont`，青绿或次级灰）
- **导航按钮**：选中态从"浅蓝底"改为"细线框 + 左侧 2px 冰蓝指示条"，更像终端菜单。
- **底部状态块**：改为 HUD 风格：
  - 第一行：小状态灯（6px 圆点，青绿=在线/琥珀=连接中/红=异常，带 1.5s 呼吸脉冲动画）+ 等宽文本 `BACKEND ONLINE`
  - 第二行：等宽小字显示连接信息（如 `LAT 12ms · KB 1280 DOC`）
  - 「待审核沙箱」按钮样式跟随 `NeuAccentButtonStyle` 微调（细线框 + 青绿数据角标）。

### 2.2 顶栏（游戏目录 / 模式 / 访问）
- 顶部 NeuPanel 右上角**新增微型 HUD 数据条**（这是承接启动动画最关键的一处）：
  ```
  TEMP 36.7°C   OXYGEN 98.4%   NET 1.8G/s   SEC A-3
  ```
  等宽字体 10.5px，青绿数字、次级灰标签，每 2 秒随机微变（有真实来源则用真实值：磁盘温度/内存/网络）。面板右上角加一个极小十字准星角标。
- 「当前大模型」文字改用 `DataFont`，模型名保持 AccentDeepBrush。
- 模式 / 访问单选按钮：选中态增加细线框 + 冰蓝文字，未选中保持次级灰。

### 2.3 聊天区
- 聊天气泡（`BubbleAssistantBrush` / `BubbleUserBrush`）保留浅粉 / 浅蓝底，但**增加 0.5px 细描边**（粉 `#F9C8DC` / 蓝 `#C9DCF8`），降低"糖果感"。
- 爱弥斯气泡左上角加 3px 状态灯（在线青绿），用户气泡不加。
- 思考过程展开面板：改为"终端日志"视觉——等宽字体、行前 `>` 前缀、青绿关键字高亮（`[接旨]`/`[规划]`/`[审议]`…）。
- 消息出现动画：气泡淡入 + 12px 上移（0.35s ease-out，stagger 60ms）。

### 2.4 面板与输入
- NeuPanel 阴影变平变轻（见设计令牌）；Inset 凹槽保持。
- 输入框 / 密码框：聚焦时从"蓝色 3px 光晕"改为"0.5px 冰蓝描边 + 微弱青绿光晕"，更克制。
- 进度条：增加细线 + 光效扫过动画（LinearGradientBrush + 平移，1.2s 循环）。

### 2.5 背景层（可选，全局）
- 主界面最底层（Grid 背景）叠一层**极淡科技网格**：1px 线 `#2E6BE6` 3% 透明度，间距 28px，可整体 60s 缓慢位移（终端的"活"感）。
- 网格在设置里提供开关，默认开。
- 扫描线只在两种时刻出现：启动动画中、AI 思考中（思考时顶栏下方一条 1px 青绿扫描线往复，1.8s/次）。常态不显示。

## 3. 动画清单（WPF Storyboard / 附加属性实现）

| 动画 | 触发 | 参数 | 说明 |
|---|---|---|---|
| 窗口启动序列 | 主窗口加载完成 | 整体 0.5s 淡入 + 12px 上移 | 承接启动动画洗白帧 |
| 面板入场 | 窗口可见 / 面板展开 | 依次淡入 + 8px 上移，间隔 60–120ms | 避免"同时弹出" |
| 状态灯呼吸 | 常驻 | 1.5s 透明度 0.5↔1 循环 | 在线/连接/异常三态 |
| HUD 数据跳动 | 每 2s | 数字滚动变化（0.3s） | 温度/氧气/网络/安全等级 |
| 消息气泡 | 新消息 | 0.35s 淡入 + 滑动 | stagger 60ms |
| 思考扫描线 | AI 思考中 | 顶栏下 1px 青绿线往复 1.8s | 与启动动画扫描线同款 |
| 进度条光效 | 进度更新 | 1.2s 光效扫过 | 细线进度条 |
| 心动模式转场 | 点击「♥ 心动模式」 | 主界面 0.3s 压暗 → 深靛画面渐显 | 见第 6 节 |
| 返回转场 | 返回控制台 | 反向：深靛 0.3s 淡出 → 主界面恢复 | |

实现建议：封装一个 `TerminalHud` 附加属性（`TerminalHud.Pulse` / `TerminalHud.Reveal`）或直接使用 XAML `EventTrigger` + `Storyboard`；所有时长集中到一个资源字典常量，方便统一调速度。

## 4. 与启动动画的衔接规则（核心验收项）

启动动画（爱弥斯版）结束后，主界面必须延续以下五点，用户才不会觉得"换了个软件"：

1. **底色连续**：启动动画阶段 7 洗白后底色 `#F5F8FC` = 主界面 `BgBrush` `#F3F6FA`（视觉上同底）。
2. **品牌块同构**：启动动画阶段 2 的"品牌三行"（Logo + `AEMEATH AGENT` + 英文副标题）与主界面侧边栏品牌块同构——同一 Logo、同一字体层级。
3. **HUD 字段一致**：启动动画阶段 3 出现的数据字段（TEMP / OXYGEN / NETWORK / SECURITY LEVEL / ARCHIVE NODE）在主界面顶栏 HUD 中继续存在、位置一致（右上角）。
4. **页脚延续**：启动动画右下角 `POWERED BY AEMEATH`；主界面右下角（或侧边栏底部）保留同样的小字页脚。
5. **色彩记忆**：启动动画中粉色只出现 2 次（Logo 光晕、欢迎语）；进入主界面后粉色只出现在品牌块、爱弥斯气泡、心动模式入口——用户记住的"粉 = 爱弥斯"语义延续。

---

## 5. 心动模式（Galgame 深靛 × 热熔粉）的衔接

心动模式是"爱弥斯的私人空间"场景，**不强行改亮**，保留深靛夜色 × 热熔粉的视觉小说质感。只做三处衔接：

1. **场景转场**（新增）：点击「♥ 心动模式」→ 主界面整体压暗 0.3s（暗色遮罩 + 虚化）→ 深靛背景渐显；返回反向。禁止生硬跳切。
2. **共享语言**：galgame 顶栏的世界时钟旁，新增一个与主界面同风格的微型 HUD 角标（`SYS ONLINE` + 青绿状态灯 + 等宽字体），两个界面有"同源终端"感。
3. **字体统一**：galgame 的英文数据元素（时间、HUD）改用 `DataFont`（Cascadia Code 系），与主界面一致；中文仍用衬线/黑体区分叙事。

不改动：深靛底色、热熔粉渐变、Ken Burns 背景、玻璃拟态气泡——它们与主界面通过转场 + 共享字体/状态灯完成衔接。

---

## 6. 性能与可访问性

- 动画全部使用 Opacity / TranslateTransform / ScaleTransform，禁止高频布局属性动画。
- HUD 数据定时器 ≤ 1Hz；窗口缩放 / 滚动期间暂停装饰性动画。
- 设置面板新增「减少动画」开关（对应 CSS `prefers-reduced-motion` 与 WPF 全局 `Timeline.DesiredFrameRate` 降级）。
- 高 DPI 下细线边框需用 `SnapsToDevicePixels` / 1px 对齐，避免模糊。
