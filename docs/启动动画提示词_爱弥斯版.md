# 爱弥斯（AEMEATH AGENT）· 科技终端风格软件启动动画 提示词（v2 爱弥斯版）

> 本版由原「莱茵生命（Rhine Lab）科技企业终端风格」提示词改编而来，可直接整体替换原 `提示词.txt`。
> 核心改动只有三处：**① 品牌与身份**（Rhine Lab → AEMEATH 爱弥斯智能体控制台）；**② 色彩桥接**（保留莱茵生命的白/银/青绿基底，融入爱弥斯品牌蓝与角色粉）；**③ 结尾衔接**（新增「过曝洗白」手法，让启动动画的最后一帧与爱弥斯白色主界面无缝衔接，两界面不冲突）。

---

请帮我制作一个「爱弥斯智能体控制台 · 生物科技企业终端风格」的软件启动动画项目。

目标不是制作普通的 Loading 页面，而是制作一个具有《明日方舟》莱茵生命科技企业宣传 PV 氛围、同时带爱弥斯角色身份的「软件启动仪式」。它服务于爱弥斯（AEMEATH）这款 AI 智能体桌面应用：冷启动时先进入一段全屏启动动画，随后无缝过渡到白色主界面。

整体视觉方向：

* 未来科技 × 生物实验室 × AI 智能体控制台
* 企业内部终端、高级、克制、冷峻
* 大量留白
* 基底：白色 / 浅灰 / 银色为主（保留莱茵生命的"科技白"基因）
* 科技主色：冰蓝 `#2E6BE6`（爱弥斯品牌蓝，用于主操作、核心数据、准星）
* 生物数据强调：青绿 `#55CBB0` / `#72E0C1`（保留莱茵生命的生物科技青绿，仅用于生命体征与生物数据）
* 角色点缀：粉 `#F0558E`（爱弥斯身份色，**克制使用**，全片只出现在三处：Logo 光晕、心跳波形、欢迎语）
* 警告：`#E8B35A` / `#D96C6C`
* 深色阶段底色：`#050708` / `#0A0D0E` / `#111516`；浅色阶段底色：`#F5F8FC` / `#FFFFFF`（与主界面完全一致）
* 极细线条、HUD 数据界面、扫描线、数据流、网格
* 微弱 CRT / 数字故障效果、轻微噪点、局部 UI 闪烁
* 精密机械感、医疗 / 生物科技 / 科研企业视觉
* 不要做成廉价赛博朋克，不要大量霓虹灯
* 不要做成普通网页 Loading 动画

核心体验：

用户启动爱弥斯之后，首先进入一个全屏启动动画。

动画建议控制在 10～20 秒左右，但必须允许用户随时跳过。

启动流程设计如下：

【阶段 1：黑场初始化】

屏幕几乎全黑（`#050708`）。

中央出现极小的系统启动文字，例如：

```
AEMEATH
AI CONSCIOUSNESS TERMINAL
SECURE TERMINAL
```

（英文副标题建议逐字打出，像终端在接收数据。）

然后出现极细的扫描线。

屏幕逐渐亮起。

右下角显示：

```
BOOT SEQUENCE 01
```

并出现非常细微的数据变化（随机小数字，等宽字体）。

---

【阶段 2：企业 Logo / 标识出现】

中央出现「原创的生物科技企业 Logo」。

注意：

* 不要直接复制《明日方舟》官方莱茵生命 Logo 素材，也不要复制《鸣潮》爱弥斯官方立绘。
* 使用爱弥斯项目自带的品牌标识 `assets/brand.png`（原创六边形 / 星环 / 生物结构形态），或在其形态基础上做原创演绎。
* Logo 必须非常简洁：六边形星环 + 中央生命体符号 + 企业字母缩写 AEMEATH 的组合。

出现方式：

微弱噪点 → 轮廓扫描 → 线框生成 → Logo 完整出现 → **一次克制的粉色光晕**（全片唯一一次粉色主视觉，约 0.6s，随后粉色退为辅助色）→ UI 数据开始运行。

同时出现：

```
AEMEATH AGENT
BIOLOGICAL RESEARCH DIVISION
```

或者用原创企业名称。

要求整体感觉像一个大型科研集团的内部启动终端，同时让用户第一眼认出这是「爱弥斯」。

---

【阶段 3：科技宣传 PV 风格转场】

不要一直停在 Logo 页面。

让大量极细 UI 线条从屏幕边缘展开。

出现（生物实验 × AI 智能体双主题）：

* 生物结构示意图
* DNA 双螺旋轮廓
* 细胞扫描
* 人体 / 生物结构轮廓
* **神经网络连接图（新增，体现 AI 智能体身份）**
* 实验数据、设备编号、坐标
* 温度、氧气、生物样本信息、研究编号
* 数据波形、实验状态

这些内容应该快速出现，然后自动消失。

不要让页面信息太满。

视觉重点是："一个真实存在的大型科研 + AI 企业终端正在启动"。

数据颜色规则：生物类数据用青绿 `#55CBB0`，系统类数据用冰蓝 `#2E6BE6`，身份类（爱弥斯相关）用粉 `#F0558E`。三种颜色各司其职，不混用。

---

【阶段 4：系统身份认证】

进入一个高级企业权限界面。

中央显示：

```
IDENTITY VERIFICATION
```

下面显示：

```
OPERATOR
RESEARCHER
AUTHORIZED PERSONNEL
```

然后出现一个交互按钮：

```
INITIALIZE SYSTEM
```

或者：

```
AUTHORIZE ACCESS
```

用户可以点击（点击或 Enter / Space 均可推进）。

点击之后出现扫描动画：

```
SCANNING...
ANALYZING BIOMETRIC DATA...
VERIFYING ACCESS...
ACCESS GRANTED
```

扫描框从屏幕上划过。

（可选：认证通过后闪过一行粉色心跳波形，提示"爱弥斯已在线"。）

---

【阶段 5：系统启动】

认证成功以后：

```
SYSTEM CORE
ONLINE
```

然后出现多个系统模块依次亮起：

```
BIOSYSTEM
AI CORE
RESEARCH NETWORK
DATA CORE
LAB CONTROL
SECURITY
ARCHIVE
```

每个模块从灰色变成青绿色 / 冰蓝色（生物类青绿、系统类冰蓝）。

右侧显示启动进度：

```
INITIALIZING SYSTEM
[████████░░] 82%
```

进度不能太普通，要做成科技终端风格（细线进度条 + 光效扫过 + 百分比等宽字体滚动）。

---

【阶段 6：故障 / 数据异常】

启动接近完成时，可以加入一次很短的异常。

例如：

```
SYSTEM CHECK
...
...
WARNING
```

屏幕突然出现：

```
DATA STREAM INTERRUPTED
```

随后画面产生轻微数字故障、图像偏移、扫描线、短暂黑屏。

注意：

* 故障效果必须高级、克制，不要做成夸张的"游戏故障特效"。
* 故障持续约 0.3～1 秒。
* 色散故障使用红色 `#D96C6C` 与冰蓝 `#2E6BE6` 的错位，不用大面积彩色噪点。

之后立即恢复正常。

---

【阶段 7：过曝洗白 + 软件正式启动】（关键改动）

这是本版与旧版最大的不同——**不要直接从故障画面切进主界面**。

故障结束、恢复正常后，画面先整体变亮：

* 0.5～0.8 秒内，背景亮度从深色快速抬升到接近纯白（`#F5F8FC`），像胶片过曝洗白，带轻微辉光。
* 洗白过程中，中央浮现：

```
SYSTEM ONLINE
```

下面：

```
WELCOME, OPERATOR
```

（可选：欢迎语用爱弥斯的身份色 `#F0558E` 以极细的粉色呈现，这是全片第二次粉色主视觉。）

* 洗白完成后，画面停留在与主界面同底色的浅色状态（白底 + 极细灰蓝边框 + 少量 HUD 数据），停留约 0.8 秒。
* 随后整个启动界面平滑淡出，正式进入爱弥斯主程序。

这样做的目的：启动动画的最后一帧与主界面的第一帧在底色、字体、元素位置上连续，用户不会感到"两个界面、两套美术"。

---

交互要求：

1. 鼠标点击可以推进部分动画（阶段 4 的按钮）。
2. Enter / Space 可以确认。
3. ESC 可以跳过启动动画。
4. 右下角有非常低调的 `SKIP` 或 `PRESS ESC TO SKIP`。
5. 第一次启动时完整播放。
6. 用户已经看过启动动画以后，可以在设置中选择：
   * 每次播放
   * 仅首次播放
   * 完全关闭
7. 支持静音。
8. 支持音量控制。
9. 动画必须能够平滑跳过，而不是直接卡死。
10. 所有转场都要有淡入淡出。

音效设计：

如果能够实现音频，请加入非常轻微的：

* 系统启动提示音
* 高频电子滴声
* 扫描音
* 数据传输音
* 机械继电器声音
* 低频环境氛围
* 权限认证成功提示音

音效不要吵。整体声音应该像"高级生物科技研究机构的内部终端启动"。认证成功提示音可以比莱茵生命原版更柔和一点，呼应爱弥斯"在星海轻歌的电子幽灵"的气质。

---

UI 设计：

字体优先使用现代无衬线字体，与主界面保持一致：

* 中文主字：Microsoft YaHei UI（主界面已有）
* 标题字：Inter / Noto Sans（与主界面品牌字一致）
* 数据等宽字：JetBrains Mono / Cascadia Code（终端数据专用）

主要 UI 元素：

* 极细边框（0.5～1px）
* 半透明面板
* 数据卡片
* 小型状态灯（青绿 = 在线 / 琥珀 = 工作中 / 红 = 异常）
* 十字准星、坐标、时间、系统编号
* 进度条、微型波形、数据流、角标、小型文字
* **中央环形准星：缓慢自转，缺口留在正下方，不遮挡底部文字（参考成熟终端启动动画的交互细节）**

所有 UI 都必须保持极简，不要让 UI 抢过主视觉。

---

颜色（爱弥斯版色板）：

深色阶段：

```
背景：#050708 / #0A0D0E / #111516
主要文字：#E8ECEC / #C9D1D1
科技强调（冰蓝）：#2E6BE6 / #4A8AF0
生物数据（青绿）：#72E0C1 / #55CBB0
角色点缀（粉）：#F0558E（全片最多出现 2 处）
辅助：#829191
警告：#E8B35A / #D96C6C
```

浅色阶段（阶段 7 洗白后，与主界面一致）：

```

主要文字：#1F2A3D
次级文字：#6B7A90
描边：#E3EAF4
强调：#2E6BE6
数据：#55CBB0
角色：#F0558E
```

不要使用大面积纯绿色；粉色的使用次数全片严格限制（Logo 光晕 1 次 + 欢迎语 1 次，至多再加认证后心跳波形 1 次）。

---

动画参数：

* 整体 60 FPS，动画必须流畅。
* 推荐 ease-out / ease-in-out / cubic-bezier。
* 避免机械地每个元素同时出现；不同 UI 元素需要存在 50～300ms 的时间差（stagger）。
* 加入少量随机数据变化，让界面看起来像真实系统。
* 数据字段示例（与主界面顶栏 HUD 一致，见前端 UI 改造提示词）：

```
TEMP 36.72°C
OXYGEN 98.4%
CELL STATUS 99.98%
NETWORK 1.82 GB/s
SECURITY LEVEL A-3
ARCHIVE NODE 07
```

这些数字可以动态变化（每 1～2s 微变）。

---

视觉构图：

* 不要始终把所有内容都堆在中央。
* 左侧显示系统状态，右侧显示数据，中央显示 Logo / 主视觉，底部显示系统信息。
* 屏幕边缘加入少量辅助 UI。
* **构图与主界面呼应**：左上角品牌块（小 Logo + AEMEATH AGENT + 英文副标题）、右上角 HUD 数据、右下角页脚 `POWERED BY AEMEATH`——这些元素在主界面同样存在，位置一致，让两界面"同源"。

---

非常重要：

* 不要直接复制《明日方舟》官方素材、角色立绘、官方 Logo、官方字体或游戏 UI。
* 不要直接复制《鸣潮》爱弥斯的官方立绘与角色素材。
* 目标是："受到莱茵生命视觉语言启发、以爱弥斯为身份的原创生物科技 AI 智能体启动终端"。
* 需要让人第一眼感受到：科研、企业、生物科技、AI、实验室、未来感、专业、高级——而不是明显的游戏 UI 复制品，也不是普通的网页 Loading。
